# Wimborne Wayfarers Hockey Club Website

Modern, interactive Node.js web application for **Wimborne Wayfarers Hockey Club** (Queen Elizabeth's Leisure Centre, Wimborne, Dorset, BH21 4DT).

## Local Development

```bash
npm run dev
```
Then open `http://localhost:3000`.

## Deploying on Hostinger (Node.js Web App)

This repository is pre-configured for **Hostinger's Node.js Web App** hosting:
- **Node Version**: `18.x`, `20.x`, or `22.x` (`>=18.0.0`)
- **Entry File**: `server.js` (or `app.js`, which aliases `server.js`)
- **Start Command**: `npm start`
- **Build Command**: `npm run build`
- **Port**: Automatically binds to `process.env.PORT` provided by Hostinger (defaults to `3000` locally).
